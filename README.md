# 📊 Sales & Analytics Dashboard

A modern, production-ready, interactive Sales & Analytics Dashboard built with **Next.js 15**, **Tailwind CSS**, and **Recharts**. Fully deployed and integrated with **Vercel** CI/CD.

![Dashboard Preview](https://img.shields.io/badge/Status-Live-emerald) ![Next.js](https://img.shields.io/badge/Next.js-15.1.0-black) ![TailwindCSS](https://img.shields.io/badge/Tailwind-3.4.1-blue)

## 🚀 Live Demo
🔗 **[View Live Dashboard](https://sales-dashboard-lzkw.vercel.app/#)** 

## ✨ Key Features
- **Interactive Revenue Charts**: Powered by `Recharts` with responsive hover metrics and smooth transitions.
- **Real-Time Data Search**: Dynamic client-side filtering for order history and customer transactions.
- **CSV Data Export**: One-click functionality to generate and download live sales reports.
- **KPI Metrics Overview**: Highlighting total revenue, active signups, orders, and conversion rates.
- **Production Optimized**: Zero build errors, stabilized dependencies, and ultra-fast page load.

## 🛠️ Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS & PostCSS
- **Visualization**: Recharts
- **Language**: TypeScript
- **Deployment**: Vercel with GitHub Integration
